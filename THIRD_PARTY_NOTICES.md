# Referências de interface

## Uiverse

Os padrões de microinteração desta interface foram estudados a partir da biblioteca pública Uiverse.
Os componentes publicados no Uiverse são disponibilizados sob licença MIT. A implementação do
GestãoLead foi reescrita e adaptada ao design system próprio, sem dependências de runtime do Uiverse.

- Projeto: https://uiverse.io/
- Licença informada pelo projeto: MIT
- Botao adaptado: https://uiverse.io/Itskrish01/wise-wombat-45
- Campo de busca adaptado: https://uiverse.io/mustafa7799/new-dolphin-33
- Input escuro adaptado: https://uiverse.io/danilppzz/tender-chicken-82
- Checkbox adaptado: https://uiverse.io/andrew-manzyk/ancient-turtle-91
- Switch adaptado: https://uiverse.io/cuzpq/gentle-goat-72
- Loader adaptado: https://uiverse.io/Shoh2008/clever-goose-73

## Profitize

A organização visual de painéis e métricas usa a Profitize apenas como referência de composição.
Nenhum componente Pro, código fechado ou ativo proprietário foi incorporado ao projeto.

- Dashboard Sidebar (Grátis): https://profitize.com.br/build/componentes/dashboard-sidebar
- Progress Metric Card (Grátis): https://profitize.com.br/build/componentes/progress-metric-card
- Indicator Chart (Grátis): https://profitize.com.br/build/componentes/indicator-chart

## Spell UI

Os componentes React foram estudados e reimplementados em HTML, CSS e JavaScript nativos.

- Pop Button: https://spell.sh/docs/pop-button
- Spinner: https://spell.sh/docs/spinner
- Chart: https://spell.sh/docs/chart
- Copy Button: https://spell.sh/docs/copy-button
- Keyboard Shortcuts: https://spell.sh/docs/keyboard-shortcuts

## Lucide

Os ícones SVG usados na navegação principal seguem os desenhos do projeto Lucide, distribuído
sob licença ISC. Os SVGs necessários foram incorporados localmente para evitar uma dependência
de runtime e reduzir requisições externas.

- Projeto: https://lucide.dev/
- Licença: ISC
